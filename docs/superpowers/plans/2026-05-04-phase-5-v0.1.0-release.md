# Phase 5 Implementation Plan: v0.1.0 release

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bump `plugin.json` to `0.1.0`, polish README to spec §11.4, finalize CHANGELOG, fix the `.claude/` housekeeping nit, then tag `v0.1.0` and publish a GitHub release.

**Architecture:** All file edits land in a single PR-B branch (`phase-5-release`), one commit per logical change. After PR-B merges to main, the controller runs the release procedure (tag + `gh release create`) — no separate PR for the release itself.

**Tech Stack:**
- bash, `git`, `gh` CLI for the release step
- No new code; pure config + docs edits

**Reference spec:** `docs/superpowers/specs/2026-05-04-phase-5-design.md`.

**Working directory:** `~/repos/github.com/jaxx2104/exiftool-skill/` on branch `phase-5-release` (off `origin/main`).

**This plan does NOT cover:**
- Building / attaching a `.skill` file to the GitHub release.
- End-to-end install verification (`/plugin marketplace add` + `/plugin install`) — that's a post-release manual smoke test by the user.

- [ ] **Step 3: Create the annotated tag**

```bash

```

- [ ] **Step 4: Create the GitHub release**

```bash
gh release create v0.1.0 \
  --title "v0.1.0" \
  --notes-from-tag
```

If the resulting release page reads thinly (just "exiftool-skill v0.1.0"), prefer:

```bash
# Extract the v0.1.0 CHANGELOG entry as release notes
python3 - <<'PY' > /tmp/v0.1.0-notes.md
import re, pathlib
text = pathlib.Path("CHANGELOG.md").read_text()
m = re.search(r'^## \[0\.1\.0\][^\n]*\n(.*?)(?=^## \[|\Z)', text, re.S | re.M)
if not m:
    raise SystemExit("could not locate v0.1.0 entry in CHANGELOG.md")
print(m.group(1).strip())
PY
gh release edit v0.1.0 --notes-file /tmp/v0.1.0-notes.md
```

- [ ] **Step 5: Verify the release exists**

```bash
gh release view v0.1.0
```

Expected: title `v0.1.0`, non-empty body, tag `v0.1.0` pointing at the merged-PR-B HEAD.
